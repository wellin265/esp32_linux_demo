# 04.advanced.korvo_board_test

## 这个工程能学什么

这是整板综合测试工程，适合了解板上功能是如何被组织成多个页面的。

## 运行效果

- LVGL 多页面界面
- 测试按键、摄像头、语音、唤醒等板载能力
