# 01.basic.hello_world

## 这个工程能学什么

这是整个仓库最适合第一步上手的工程。

它演示最基本的 ESP-IDF 入口、芯片信息读取、Flash 信息读取和屏幕状态输出。

## 运行后你会看到什么

- 串口打印芯片型号、核心数、Flash 大小等信息
- 屏幕显示项目名和当前芯片信息
- 工程运行稳定，适合拿来测试环境是否完整

## 关键文件

- `main/hello_world_main.c`

## 代码做了什么

主流程是：

1. 初始化显示界面
2. 读取芯片信息
3. 读取 Flash 信息
4. 组织三行状态文本
5. 同时输出到串口和屏幕

## 建议重点看哪几段

- `app_main()`
- `esp_chip_info()`
- Flash 信息读取逻辑
- `ksdiy_example_display_set_lines()`

## 你会学到的知识点

- ESP-IDF 工程入口在哪里
- 最简单的串口日志怎么写
- 一个“能运行”的工程最小长什么样

## 第一次建议你改什么

- 改屏幕标题文字
- 多打印一条你自己的日志
- 加一个周期性计数器确认主循环在跑
