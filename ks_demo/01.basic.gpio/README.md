# 01.basic.gpio

## 这个工程能学什么

这个例子比 `blink` 更完整，演示了 GPIO 输出、GPIO 输入、中断和任务队列配合。

它很适合用来理解“外部引脚变化怎么传到应用层”。

## 运行后你会看到什么

- GPIO19 和 GPIO20 周期性翻转
- GPIO5 输入变化会触发中断
- 串口打印中断次数和引脚状态
- 屏幕显示输出、输入和最近一次中断信息

## 关键文件

- `main/gpio_example_main.c`

## 代码做了什么

主流程是：

1. 初始化显示
2. 配置两个输出 GPIO
3. 配置一个输入 GPIO 和中断类型
4. 创建事件队列
5. 中断里把事件塞进队列
6. 任务从队列取事件并打印
7. 主循环持续切换输出电平

## 建议重点看哪几段

- `gpio_config()`
- `gpio_isr_handler()`
- `gpio_task_example()`
- `xQueueSendFromISR()`

## 你会学到的知识点

- GPIO 输入输出的区别
- 为什么中断里不适合做复杂逻辑
- 为什么中断常常要配合队列和任务一起用

## 第一次建议你改什么

- 改输出 GPIO 引脚
- 把输入中断从任意边沿改成上升沿
- 在屏幕上增加更多状态信息
