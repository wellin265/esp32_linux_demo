# MYIIC — I2C 总线驱动

## 硬件连接

| 引脚 | GPIO | 说明 |
|------|------|------|
| SDA | 17 | I2C 数据线 |
| SCL | 18 | I2C 时钟线 |

## 总线配置

| 参数 | 值 | 说明 |
|------|-----|------|
| I2C 端口 | I2C_NUM_0 | |
| 时钟频率 | 400kHz | |
| 内部上拉 | 启用 | |

## 共用设备

| 设备 | 地址 | 驱动 |
|------|------|------|
| TCA9554 | 0x20 | IO 扩展 (LCD 供电/复位) |
| CST816S | 0x15 | 电容触摸 |

## 实现说明

- 单例模式 (`MyIic::inst()`)，多设备共用一条总线
- `s_initialized` 标志防止重复初始化
- 初始化顺序: `Tca9554::init()` → `Cst816s::init()` 各自内部调用 `MyIic::init()`
