# MYSPI — SPI 总线驱动

## 硬件连接

| 引脚 | GPIO | 说明 |
|------|------|------|
| SCLK | 1 | SPI 时钟 |
| MOSI | 0 | SPI 数据 (主机输出) |
| MISO | NC | 未使用 (LCD 只写) |

## 总线配置

| 参数 | 值 | 说明 |
|------|-----|------|
| SPI 主机 | SPI2_HOST | |
| 传输大小 | 320×240×2 | 一帧全屏数据 |
| DMA | 自动分配 | |

## 从设备

| 设备 | CS | DC | 说明 |
|------|-----|-----|------|
| ST7789 | GPIO 46 | GPIO 2 | 280×240 LCD |

## 实现说明

- 单例模式，`s_initialized` 防止重复初始化
- CS 由 `esp_lcd_panel_io_spi` 自动控制，不需要手动操作
- 只写模式 (MISO 未连接)
