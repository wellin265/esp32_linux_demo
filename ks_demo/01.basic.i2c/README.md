# 01.basic.i2c

## 这个工程能学什么

这个例子演示 I2C 主机初始化、总线扫描，以及对 CST816 触摸芯片的基础读取。

它很适合第一次真正和外部芯片通信时使用。

## 运行后你会看到什么

- 串口打印 I2C 总线扫描结果
- 屏幕显示 SDA/SCL 引脚和找到的设备数量
- 如果检测到 CST816，程序会继续读取触摸相关寄存器

## 关键文件

- `main/i2c_basic_example_main.c`

## 代码做了什么

主流程是：

1. 初始化显示
2. 配置 I2C master 总线
3. 扫描 7-bit 地址范围内的设备
4. 把找到的设备数量显示出来
5. 尝试添加 CST816 设备并做读取循环

## 建议重点看哪几段

- `i2c_master_init()`
- `i2c_scan_devices()`
- `cst816_register_read()`
- `cst816_read_loop()`

## 你会学到的知识点

- I2C 主机初始化流程
- 设备扫描的典型写法
- 总线句柄和设备句柄的区别

## 第一次建议你改什么

- 改 I2C 引脚
- 扩展扫描结果显示
- 替换成你自己的 I2C 设备地址做测试
