# 03.development.usb_4g_module

## 这个工程能学什么

这个例子演示通过 USB 连接 4G 模块，并结合 Wi-Fi/NVS/HTTP 做更完整的联网流程。

## 运行效果

- 初始化 USB 模块通信
- 管理网络配置
- 发起 HTTP 请求或网络业务

## 关键文件

- `main/app_main.c`
- `main/sta_manager.c`
- `main/modem_http_config.c`
- `main/nvs_storage.c`
