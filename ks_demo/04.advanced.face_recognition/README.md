# 04.advanced.face_recognition

## 这个工程能学什么

这是一个综合型视觉 AI 示例，包含摄像头、LVGL 和多种识别逻辑。

## 运行效果

- 摄像头实时取流
- 可进行人脸检测、人脸识别、运动检测、颜色检测等
- 屏幕实时显示识别结果

## 关键文件

- `main/app_main.cpp`
- `main/camera_lvgl_view.c`
- `main/who_human_face_detection.cpp`
- `main/who_human_face_recognition.cpp`
- `main/event_logic.cpp`
