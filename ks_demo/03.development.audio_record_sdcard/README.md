# 03.development.audio_record_sdcard

## 这个工程能学什么

这个例子把录音、文件系统和 UI 结合起来，适合学“可保存的录音机”。

## 运行效果

- 录音写入 SD 卡
- 可读取并播放 WAV 文件
- 屏幕显示录音界面和文件状态

## 关键文件

- `main/app_main.c`
- `main/fs_manager.c`
- `main/wav_handler.c`
- `main/ui_record.c`
