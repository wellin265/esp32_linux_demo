# 02.beginner.ota

## 这个工程能学什么

这个例子演示 HTTPS OTA 升级，是把“联网”真正推进到“可远程更新设备”这一步。

## 运行效果

- 设备连接到升级服务器
- 下载新固件
- 校验并写入 OTA 分区
- 成功后重启到新固件
- 屏幕显示连接、下载、失败或完成状态

## 关键文件

- `main/simple_ota_example.c`

## 重点理解

- OTA 依赖稳定网络和正确证书
- OTA 不是下载一个文件就结束，还包括分区切换和重启
- HTTP 事件回调能帮助观察升级过程

## 建议先改什么

- 换成自己的 OTA 地址
- 把版本号显示到屏幕
- 增加失败后的重试策略说明
