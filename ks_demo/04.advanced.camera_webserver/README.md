# 04.advanced.camera_webserver

## 这个工程能学什么

演示摄像头画面通过网页流式预览，是“远程看图像”的基础模板。

## 运行效果

- 连接 Wi-Fi
- 摄像头取流
- 启动 HTTP 视频流服务
- 浏览器访问查看画面

## 关键文件

- `main/app_main.c`
- `main/app_camera.c`
- `main/app_http_stream.c`
- `main/app_wifi.c`
