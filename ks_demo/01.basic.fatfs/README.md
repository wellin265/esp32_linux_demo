# 01.basic.fatfs

## 这个工程能学什么

这个例子演示在 Flash 上挂载 FAT 文件系统，并进行基础文件操作。

如果你已经看过 `01.basic.spiffs`，这个工程很适合用来对比两种文件系统风格。

## 运行后你会看到什么

- 屏幕显示 FATFS 挂载状态
- 串口输出文件系统操作结果
- 例子会执行挂载、文件操作和状态更新

## 关键文件

- `main/fatfs_getting_started_main.c`

## 代码做了什么

主流程是：

1. 初始化显示
2. 挂载 FAT 文件系统
3. 执行文件读写相关动作
4. 把当前阶段显示到屏幕上

## 建议重点看哪几段

- 文件系统挂载配置
- 文件创建与读取
- `update_display()`

## 你会学到的知识点

- FATFS 在嵌入式里的基本用法
- 文件系统初始化失败时要怎么排查
- 文件系统类工程为什么适合用串口和屏幕双重反馈

## 第一次建议你改什么

- 改写入文件的内容
- 增加一个新文件
- 对比和 `SPIFFS` 的使用差别
